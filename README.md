# PaisaWise - Smart Student Expense Tracker

PaisaWise is a full-stack web application designed to help students manage and understand their daily expenses.

It allows users to record expenses, organise them into categories, track their monthly budget, view spending summaries, and get useful spending insights. It also includes an AI-powered expense parsing feature that can convert natural-language expense statements into structured expense information.

## Features

### Expense Management

- Add new expenses
- View all recorded expenses
- Update existing expenses
- Delete expenses
- Store amount, category, merchant, note, and date

### Spending Dashboard

The dashboard provides an overview of financial activity:

- Total amount spent
- Number of transactions
- Highest spending category
- Spending overview
- Number of categories used

### Budget Tracking

Users can set a monthly budget and track:

- Monthly budget
- Total spent
- Remaining amount
- Percentage of budget used

### AI Expense Parsing

PaisaWise includes an AI-powered expense parser.

Users can enter an expense as a natural-language statement instead of manually filling every field.
